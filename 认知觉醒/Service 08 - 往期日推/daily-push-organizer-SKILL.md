# 日推文件整理工具

将同名的 `.mp3` 和 `.pdf` 文件整理到结构化文件夹中，并生成 Obsidian 格式的 Markdown 笔记。

## 使用场景

用户有多个 `.mp3` 和 `.pdf` 文件，需要：
1. 将同名文件归类到同一文件夹
2. 从文章列表中提取日期和标签（不读取PDF，提升速度）
3. 创建符合命名规范的文件夹结构
4. 生成包含文件链接的 Markdown 笔记

**重要**：仅处理当前工作目录下的文件，不递归处理子文件夹。

## 执行步骤

### 1. 扫描文件

搜索当前目录下的音频和 PDF 文件（仅限当前目录，不包含子文件夹）：

**扩展名不区分大小写**：支持 `.mp3`、`.MP3`、`.Mp3` 和 `.pdf`、`.PDF`、`.Pdf` 等各种大小写组合。

**重要**：`glob` 工具默认大小写敏感，必须使用 bash 命令实现大小写不敏感搜索：

```bash
# 使用 bash 开启大小写不敏感匹配
shopt -s nocaseglob
ls *.mp3 *.pdf 2>/dev/null
# 或者使用 find 命令
find . -maxdepth 1 -type f \( -iname "*.mp3" -o -iname "*.pdf" \)
```

如果使用 glob 工具，需要分别搜索所有大小写组合：

**mp3 的 4 种组合**（m、p 可变，3是数字）：
```
glob: "*.mp3"
glob: "*.mP3"
glob: "*.Mp3"
glob: "*.MP3"
```

**pdf 的 8 种组合**（p、d、f 都可变）：
```
glob: "*.pdf"
glob: "*.pdF"
glob: "*.pDf"
glob: "*.pDF"
glob: "*.Pdf"
glob: "*.PdF"
glob: "*.PDf"
glob: "*.PDF"
```

然后将结果合并去重。

### 2. 匹配同名文件

提取文件名（不含扩展名），匹配同名的音频和 PDF 文件对（忽略扩展名大小写差异）。

### 3. 从文章列表提取日期和标签

**优先方式**：读取当前目录下的 `文章列表.md` 文件，根据文件名匹配对应的日期和标签。

文章列表格式示例：
```markdown
| 序号 | 标题 | 日期 | 标签 | 简介 |
|------|------|------|------|------|
| 1 | 高效学习：学得更快，记得更牢 | 2026/05/29 | 高效学习 | 学习是主动突破认知边界的持续过程 |
```

匹配规则：
1. 读取 `文章列表.md` 文件
2. 解析表格中的"标题"、"日期"、"标签"、"简介"列
3. 将待整理的文件名与表格中的标题进行匹配（去除特殊字符后模糊匹配）
4. 提取匹配行的日期、标签和简介

**备选方式**：如果 `文章列表.md` 不存在，则从 PDF 文件内容中提取：
- 日期格式：`日推 YYYY/MM/DD`
- 标签格式：`分类 标签名`

### 4. 创建文件夹

文件夹命名格式：`日期-标签-文件名`
- 日期：转为 `YYYY-MM-DD` 格式
- 标签：直接使用提取的标签文本
- 文件名：原文件名（去除扩展名，去除冒号等特殊字符）

示例：
- 文章列表匹配：标题 `高效学习：学得更快，记得更牢` → 日期 `2026/05/29` → 标签 `高效学习`
- 文件夹名：`2026-05-29-高效学习-高效学习学得更快记得更牢`

### 5. 移动文件

将 `.mp3` 和 `.pdf` 文件移动到新创建的文件夹中。

### 6. 创建 Markdown 笔记

在文件夹中创建同名的 `.md` 文件，使用以下模板：

```markdown
---
date: YYYY-MM-DD
tags:
  - 标签名
---

## 相关文件

- 📄 [[文件名.pdf|PDF文档]]
- 🎵 [[文件名.mp3|音频文件]]

## 简介

（从文章列表提取的简介内容）
```

**Obsidian 格式要求**：
- YAML frontmatter 包含 `date` 和 `tags`
- 标签使用 `#标签名` 格式
- 文件链接使用 `[[文件名.pdf|显示文本]]` 格式

### 7. 验证结果

列出文件夹内容，确认所有文件都已正确归档。

## 完整工作流示例

输入文件：
- `高效学习：学得更快，记得更牢.mp3`
- `高效学习：学得更快，记得更牢.pdf`
- `文章列表.md`（包含该文章的日期和标签信息）

执行后生成：
```
2026-05-29-高效学习-高效学习学得更快记得更牢/
├── 高效学习：学得更快，记得更牢.mp3
├── 高效学习：学得更快，记得更牢.pdf
└── 高效学习：学得更快，记得更牢.md
```

## 注意事项

1. **仅处理当前目录**：不递归扫描子文件夹，子文件夹内的文件会被忽略

2. **扩展名大小写不敏感**：

   mp3 的 4 种格式：`.mp3`、`.mP3`、`.Mp3`、`.MP3`
   
   pdf 的 8 种格式：`.pdf`、`.pdF`、`.pDf`、`.pDF`、`.Pdf`、`.PdF`、`.PDf`、`.PDF`

   上述所有格式均可识别为同类文件

3. **优先使用文章列表**：从 `文章列表.md` 提取信息比读取 PDF 更快

4. **模糊匹配**：文件名与标题匹配时，忽略冒号、空格等特殊字符差异

5. 如果文章列表中找不到匹配项，再尝试从 PDF 内容提取

6. 如果仍无法提取日期或标签，询问用户如何处理

7. 文件夹名称中的特殊字符（如冒号）需去除或替换

8. 如果同名文件对不存在，单独处理已匹配的部分并告知用户

9. 保持 Markdown 文件的编码为 UTF-8
